**Ancaman Ransomware Baru Mengintai Infrastruktur Cloud-Native**

Sebuah varian ransomware baru baru-baru ini terdeteksi menargetkan infrastruktur cloud publik dengan mengeksploitasi kerentanan pada API Kubernetes. Mayoritas perusahaan saat ini sangat bergantung pada arsitektur *cloud-native*, menjadikan celah ini sangat kritis.

**Dampak:**
Ransomware ini dapat mengambil alih kluster secara penuh, mengenkripsi data pada *Persistent Volumes*, dan meminta tebusan dalam bentuk kripto.

**Langkah Mitigasi:**
1. Lakukan audit konfigurasi **RBAC (Role-Based Access Control)** secara berkala.
2. Batasi akses publik ke API server Kubernetes.
3. Selalu perbarui versi Kubernetes ke *patch* keamanan terbaru.
